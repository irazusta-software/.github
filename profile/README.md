# Irazusta Software

Independent software studio in the Basque Country, Spain. We build focused tools for real operational problems.

## Public Jira apps

- [ScopeProfit for Jira](https://marketplace.atlassian.com/apps/4226574581/scopeprofit-for-jira) — review scope changes and forecast project margin.
- [Worklog Check for Jira](https://marketplace.atlassian.com/apps/853512273/worklog-check-for-jira) — review worklog entries before reporting or invoicing.
- [Dependency Signal for Jira](https://marketplace.atlassian.com/apps/1630778508/dependency-signal-for-jira) — review dependency risks, blockers and date conflicts.
- [Form Drift Check for Jira Service Management](https://marketplace.atlassian.com/apps/3951050126/form-drift-check-for-jsm) — compare supported linked form answers with Jira fields.
- [Estimate Bench for Jira](https://marketplace.atlassian.com/apps/4108628376/estimate-bench-for-jira) — compare estimates with completed work and sample sizes.
- [Queue Coverage for Jira Service Management](https://marketplace.atlassian.com/apps/337462882/queue-coverage-for-jsm) — review active requests against selected queues.

Check each official Marketplace listing for current availability and installation details. Some existing listings retain the legacy vendor name ProfitSignal Labs.
